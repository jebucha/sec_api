## 3. Design Decision Alignment

### D1: `reasoning_text` canonical field
- Added to `Canonical` dataclass as `reasoning_text: tuple[str, ...] = ()` ✓
- Added to `CANONICAL_FIELDS` set ✓
- Added to `RULE_SCHEMA` target enum in `src/llmgw/rules/loader.py` ✓
- Added to `rules/schema.json` published schema ✓
- Added to `TEXT_FIELDS` in `src/llmgw/replay/corpus.py` ✓
- Parity between embedded RULE_SCHEMA and published schema enforced by test ✓
- Module docstring updated with reasoning_text and malformed reasoning gap kind ✓

### D2: One segment per message or per accumulated stream
- Non-streaming OpenAI: one `reasoning_text` segment per message ✓
- Non-streaming Anthropic: one segment per `thinking` block ✓
- Streamed OpenAI: all `delta.reasoning_content` fragments accumulated into one segment ✓
- Streamed Anthropic: `thinking_delta` fragments accumulated into one segment at `content_block_stop` ✓

### D3: Extraction at all entry points
- OpenAI `parse_request`: extracts `message.reasoning_content` ✓
- OpenAI `parse_response`: extracts `message.reasoning_content` ✓
- OpenAI `extract_stream_text`: accumulates `delta.reasoning_content`, whitelists `"reasoning_content"` ✓
- Anthropic `_route_block`/`_parse_blocks`: handles `type: "thinking"` blocks ✓
- Anthropic `extract_stream_text`: `content_block_start` opens slot, `thinking_delta` accumulates, `content_block_stop` closes ✓

### D4: Replay corpus and docs
- `TEXT_FIELDS` includes `reasoning_text` ✓
- `docs/rules.md` field reference updated with `reasoning_text` ✓
- Docs note that reasoning/thinking content is inspected at both stages ✓

### D5: Starter pack PL-001 targets `reasoning_text`
- `rules/prompt-leak.jsonl` PL-001 `target` includes `reasoning_text` ✓
- Version bumped from `"1"` to `"2"` ✓

### D6: `_emit_gaps` deduplication with `count`
- `_emit_gaps` groups by `(kind, location, detail)` with insertion-order-preserving dict ✓
- Emits one event per group with `count` field ✓
- `uninspected_content_event` signature includes `count: int = 1` (default=1, additive) ✓
- `Canonical.uninspected` retains all gaps for `fail_closed` semantics ✓

### D7: Anthropic `signature_delta` silently ignored
- `content_block_start` with `type: "thinking"` opens a slot; other `type` values remain gaps ✓
- `thinking_delta` only accumulated if slot is open ✓
- `signature_delta` is treated as protocol-only (no gap emitted) ✓
- Test T-028 asserts no uninspected events for thinking or signature events ✓
